Pyramids

Each row is a clue for one across answer. The next row contains exactly the same letters as the row above, plus one new letter.

How to play

Start with the one-letter answer at the top. Every row below gets one letter longer. The letters from the previous row must all appear in the next answer, with exactly one additional letter added. Letter order may change. There is no Down crossword — every clue is Across.
