Pyramids

Each row is a clue for one across answer. The next row contains exactly the same letters as the row above, plus one new letter.

How to play

Start with the one-letter opening answer. There are two possible opening letters. The letter you choose determines which clue path you receive. Every next answer contains all letters from the previous answer plus exactly one new Serbian letter. Letter order may change. There is no Down crossword. NJ, LJ and DŽ each count as one letter.
